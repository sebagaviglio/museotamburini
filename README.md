# Museo Tamburini · Etapa 1 (boceto v4)
Estructura de la home según el esquema de contenidos:
01 Apertura audiovisual · 02 Descubrí Tamburini · 03 Arte, tecnología y nuevas narrativas · 04 Infancias · 05 Explorá de otra manera · 06 El museo hoy

- Videos de capítulos 02–04: completar `video` en CHAPS dentro de `build.py` (mp4 en loop, sin sonido).
- Recorridos de 05: definidos en `assets/site.js` (constante XP).
- Agenda y URLs propias: `data/muestras.json` (campos `tipo`: Muestra / Actividad / Visita guiada; `eje`: patrimonio / arte / infancias).
- Regenerar: `python _src/build.py`
